# Had 3D

Hra pro telefon: **had se ovládá jen švihnutím prstu** tam, kam má jet.
3D grafika, řetězec za rychlé sbírání, zlaté bonusy, dvě kůže hada
(neonová a zelená se skvrnami) a rekord, co přežije zavření.

**Hrát: https://pavel-pe899.github.io/had-3d/**

Stačí prohlížeč v telefonu, nic se neinstaluje.

---

V tomhle repozitáři je **jen sestavená hra** — tedy to, co pošle
prohlížeč návštěvníkovi. Zdrojový kód, testy a poznámky k vývoji
žijí jinde.

```
index.html   stránka, která hru spustí
bundle/      samotná hra slepená do jednoho souboru
.nojekyll    aby GitHub soubory nepřepisoval po svém
```

Hra je postavená v Expo (React Native) a Three.js.
